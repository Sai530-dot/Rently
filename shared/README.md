# Shared Types and Constants

This folder contains shared code between frontend and backend.

## 📁 Structure

```
shared/
├── types/           # TypeScript type definitions
├── constants/       # Shared constants and enums
├── utils/           # Shared utility functions
└── validators/      # Shared validation schemas
```

## 🔧 Usage

These shared modules can be imported by both frontend and backend applications to maintain consistency across the codebase.

### Types
- User types (Student, Landlord)
- Property types
- API response types
- Form validation types

### Constants
- API endpoints
- User roles
- Property categories
- Error messages

### Utils
- Date formatting
- String manipulation
- Validation helpers
- Common calculations

### Validators
- Email validation
- Password strength
- Phone number format
- Property data validation
