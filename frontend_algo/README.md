# Reelty Preferences UI

A beautiful React-based roommate matching preferences interface matching the Reelty design system. This is a multi-page form for collecting user preferences including budget, location, sleep schedule, and number of roommates.

## Current Status

**Page 1 - Budget Preference** ✅ Complete

- Slider and dropdown input options
- Beautiful UI matching Reelty's pink and white color scheme
- Fully functional with data persistence

**Page 2 - Location Preference** ✅ Complete

- Address autocomplete using Geoapify API
- Real-time suggestions as you type
- Interactive map preview with OpenStreetMap
- Full location data saved (address, coordinates, city, state, country)
- Environment variable for API key security

**Page 3 - Sleep Schedule** ✅ Complete

- Time picker and dropdown options
- Range of bedtime options from before 10 PM to after 2 AM
- Toggle between time picker and dropdown
- Data persistence and validation

**Page 4** 🚧 Coming Soon

- Number of Roommates selection (1-4)
